# লাইভ ট্রেডিং সিগন্যাল

Python (RSI + EMA) → Supabase → Realtime ড্যাশবোর্ড।

## সেটআপ
1. Supabase SQL Editor-এ `schema.sql` চালান।
2. Render → New → Blueprint → এই রিপো সিলেক্ট করুন।
3. `SUPABASE_KEY`-এ Supabase-এর **Secret key** বসান (GitHub-এ নয়)।
4. `signal-dashboard` লিংকই আপনার লাইভ সাইট।
5. ফ্রি প্ল্যানে ঘুম এড়াতে UptimeRobot দিয়ে `signal-engine` URL প্রতি ৫ মিনিটে পিং করান।

⚠️ বাইনারি অপশন অত্যন্ত ঝুঁকিপূর্ণ। কোনো সিগন্যালই লাভের নিশ্চয়তা দেয় না।
